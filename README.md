
# ElementLab

An interactive playground to explore HTML elements, CSS techniques, and JavaScript browser APIs.

Explore practical demonstrations of HTML elements, understand how they work, and experiment with interactive examples.


## Features

- Interactive Canvas drawing with color selection and clearing.
- Embedded content demonstrations using `<embed>` and `<object>`.
- Responsive images using `<picture>` and `<source>`.
- Video captions using `<track>`.
- Table column styling using `<colgroup>` and `<col>`.
- Custom elements using `<template>`, `<slot>`, and Shadow DOM.
- JavaScript fallback demonstration using `<noscript>`.
- Ruby annotations using `<rt>` and `<rp>`.
- Geolocation demonstration with browser permission.
- Search functionality to find HTML element demonstrations.
- Responsive layout for different screen sizes.


## Technologies Used

- **HTML5** – Structure and semantic elements.
- **CSS3** – Styling, layouts, and responsive design.
- **JavaScript (Vanilla)** – DOM manipulation and browser APIs.
- **Git & GitHub** – Version control and project management.


## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/xajdys/element-lab.git
   ```

2. Open the project folder:

   ```bash
   cd element-lab
   ```

3. Open `index.html` in your browser.

   You can also use the **Live Server** extension in VS Code for a local development server.
